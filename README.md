# Backend-Escuela

Desarrollo de un sistema educativo para el control de notas y estudiantes utilizando Python.

## Características

- Gestión de estudiantes: registro, edición y eliminación de información.
- Control de notas: asignación, edición y cálculo de promedios.
- Interfaz sencilla y funcional para la administración de datos.
- Backend desarrollado con Python.

## 🏗️ Estructura del Proyecto


📁 entidades
│ ├── persona.py
│ ├── estudiante.py
│ ├── profesor.py
│ └── materia.py
│
📄 main.py
📄 README.md


## 🧠 Arquitectura

El sistema está construido bajo el paradigma de Programación Orientada a Objetos:

- **Persona** → Clase base
- **Estudiante** → Hereda de Persona
- **Profesor** → Hereda de Persona
- **Materia** → Clase independiente con validaciones

Se aplican conceptos como:

- Herencia
- Encapsulamiento
- Métodos especiales (`__str__`)
- Validación de datos
- Tipado estático (type hints)
